## Explicitly unfinished external items

Independent email/password provider; mail credentials/real delivery; operator contact/jurisdiction/final policies; custom domain/DNS; independent encrypted backup destination/key vault, persistent maintenance scheduler, monitoring/billing alerts; public access choice; owner authenticator enrollment. These are skipped as requested, not represented as completed. Database and media recovery tooling is implemented and locally tested; an actual hosted disaster recovery exercise remains an operator task.

Local development/test data and keys live only under ignored `.env` / `.sites-runtime` / `.wrangler` paths. Production starts from migrations and labelled starter content, not the local test database. The production staff encryption key is separately generated and stored in a private local runtime file and hosted secret; move its backup to a secure vault before public operation.
